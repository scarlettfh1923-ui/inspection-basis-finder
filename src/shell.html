DeepSeek 网页搜索 收费

单文件版的网页搜索只能通过 DeepSeek Search API（浏览器无法直接调用百度等搜索引擎）。按成功请求计费（官方价 $0.75 / 千次），每个项目约 2 次。关闭则只检索知识库。

DeepSeek 网页抓取 收费

用 DeepSeek Fetch API 抓取搜索结果的全文（Markdown）。按成功请求计费（$0.75 / 千次），每个项目约 3–8 次。关闭则只用搜索结果自带的摘要与正文。
